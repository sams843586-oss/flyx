# Flyx для Linux

Первая Linux-сборка: **x86_64 / amd64, Debian 12+ и Ubuntu 24.04+ с systemd**. Окно запускается от обычного пользователя; правами на VPN-туннель обладает отдельная служба. ARM и дистрибутивы без systemd в эту сборку не входят.

Это тестовый выпуск: бинарные файлы собраны для Linux из Windows с Linux-библиотеками. Запуск окна и реальное TUN-подключение на Linux ещё не проверены — проверка на реальном Linux ещё требуется.

## Установка пакета

В папке со скачанным `.deb`:

```bash
sudo apt install ./flyx-vpn_0.1.0_amd64.deb
sudo usermod -aG flyx "$USER"
```

Выйдите из сеанса Linux и войдите снова, чтобы применилось членство в группе `flyx`. Затем откройте **Flyx** из меню приложений или командой `flyx`. Не запускайте графическое окно через `sudo`.

Пакет содержит приложение, консольный клиент, службу, sing-box **1.14.4** и Xray **26.11.9**. Служба включается при установке и запускается вместе с системой; само окно автоматически при входе не открывается. Установка ядер из стороннего менеджера не требуется.

```bash
systemctl status flyx
flexconnect svc status
sudo journalctl -u flyx -n 80 --no-pager
```

Переключатель «Запуск в трее» относится к запуску окна Flyx, а не к автозапуску при входе. В GNOME для видимого значка трея может понадобиться расширение AppIndicator; в других окружениях используйте их поддержку системного трея. Меню значка позволяет открыть окно или отключить VPN и выйти.

## Что перенесено

- Интерфейс Flyx, три темы, девять языков, анимированные стикеры и флаги.
- Прозрачная анимация Flyx наверху настроек, серверов и правил. На двух новых вкладках используется GIF; вне экрана и в фоне остаётся статичный кадр.
- Импорт и обновление подписок, выбор сервера и автоподключение.
- TUN для системного трафика и локальный HTTP/SOCKS-прокси.
- Прямые домены, российский каталог, правила по имени процесса.
- Настройки и постоянный ID установки в `$XDG_CONFIG_HOME/flyx` или `~/.config/flyx`. Файлы с ключами доступны только владельцу.

В правилах приложений вводите **имя Linux-процесса**, например `firefox` или `telegram-desktop`. Суффикс `.exe` в Linux не добавляется; регистр сохраняется. Имена процессов приложений в Flatpak/Snap могут отличаться — проверьте фактическое имя. Windows-настройки и подписки автоматически между системами не синхронизируются.

В режиме локального прокси задайте приложению адрес `127.0.0.1` и выбранный порт вручную. Этот режим не включает системный VPN сам по себе. TUN создаёт маршруты и использует Linux `auto_redirect`; механизм DNS интегрируется с systemd-resolved, если он доступен. Kill Switch в этой версии не реализован.

## Архив вместо .deb

Для поддерживаемой системы можно распаковать `Flyx-Linux-x86_64-0.1.0.tar.gz` и выполнить `sudo sh install.sh`. Зависимости должны быть установлены заранее:

```bash
sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0 libayatana-appindicator3-1 \
  libssl3 ca-certificates iproute2 nftables xdg-utils
```

В Ubuntu некоторые пакеты имеют суффикс `t64`; для обычной установки предпочтителен `.deb`, который разрешает зависимости через apt. Установка из архива не регистрирует пакет в dpkg. Для удаления такой установки остановите `flyx.service` и удалите только перечисленные в `install.sh` файлы. Пакет `.deb` удаляется командой `sudo apt remove flyx-vpn`; пользовательские подписки сохраняются.

## Сборка из исходников

Нужны Rust/Cargo, Python 3 и Linux-зависимости Tauri:

```bash
sudo apt update
sudo apt install build-essential pkg-config libssl-dev libgtk-3-dev \
  libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev python3
bash tools/build-linux.sh
```

Готовые файлы появятся в `output/Linux/`. Сборщик скачивает закреплённые версии ядер из официальных GitHub-релизов и проверяет SHA256. Пути ядер в установленной службе фиксированы: `/usr/lib/flyx`; каталог и исполняемые файлы должны принадлежать root и быть недоступны другим пользователям для записи.

Служба принимает ограниченные JSON-запросы через `/run/flexconnect/control.sock` с правами `0660`, доступными root и группе `flyx`. Она не слушает TCP-порт. systemd завершает группу процессов ядер при остановке службы; дочерние ядра также получают сигнал при аварийном завершении родителя.

Технические источники: [зависимости Tauri](https://v2.tauri.app/start/prerequisites/), [TUN в sing-box](https://sing-box.sagernet.org/configuration/inbound/tun/), [sing-box 1.14.4](https://github.com/SagerNet/sing-box/releases/tag/v1.14.4), [Xray 26.11.9](https://github.com/XTLS/Xray-core/releases/tag/v26.11.9).

## Проверка перед стабильным выпуском

1. Установить `.deb`, добавить свой аккаунт в группу `flyx`, выйти из сеанса и войти снова.
2. Запустить Flyx обычным пользователем; добавить подписку и проверить смену тем/языков и анимации трёх вкладок.
3. Подключить сервер в режиме «Весь компьютер», открыть сайты и проверить внешний IP. Затем отключиться и проверить восстановление обычного интернета.
4. Проверить смену страны при подключении, прямые домены, сворачивание в трей и повторное открытие окна из меню значка.
5. При ошибке прислать название/версию дистрибутива, текст ошибки в Flyx и журнал:

```bash
systemctl status flyx --no-pager
sudo journalctl -u flyx -n 100 --no-pager
flexconnect svc logs -n 100
```

## Подписанные обновления

Проверка доступна в настройках. Пакет проверяется закреплённым ключом Minisign до установки. Для установки .deb используется pkexec/dpkg с системным запросом прав администратора; доступ к интернету и установленный polkit agent могут потребоваться. Текущий экспериментальный выпуск ещё нуждается в проверке полного обновления на Linux.
